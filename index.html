How a workout gets here

  1. Write it down

    I log sets and reps in Apple Notes at the gym. An iOS Shortcut runs when I close Notes and posts any new workout to an HTTP endpoint.

  2. Land in storage

    Each note is saved as a raw file in a Google Cloud Storage bucket, so the original text is always kept.

  3. Clean and model

    BigQuery loads the raw data and refines it through bronze, silver, and gold layers. Views like v_workout_summary feed the dashboard.

  4. See the trend

    Data Studio reads the gold views and charts weekly volume and workout frequency, refreshing as new sessions arrive.

What it tracks

Weekly volume

Total pounds lifted per week (weight × reps × sets), grouped by Monday-start weeks.

Training frequency

Sessions per week, to spot consistent blocks and missed weeks.

Session detail

Duration, exercise count, and working sets for every workout.
